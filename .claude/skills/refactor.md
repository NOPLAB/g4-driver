# リファクタリング

指定されたコードを分析し、リファクタリングを行います。

## 手順

1. **対象の特定**: ユーザーが指定したファイル、関数、またはコード範囲を読み込む
2. **分析**: 以下の観点でコードを分析する
   - 可読性（命名、構造、コメント）
   - 重複コード
   - 関数/モジュールの責務分離
   - エラーハンドリング
   - パフォーマンス
3. **提案**: 改善点をリストアップし、優先度と理由を説明する
4. **確認**: ユーザーに実施する改善を選択してもらう
5. **実装**: 承認された改善のみを実施する

## 重要事項

- 既存の動作を変更しない（機能的に等価であること）
- 一度に大きな変更をしない。段階的に改善する
- 変更前後でテストやビルドが通ることを確認する
- 過度な抽象化を避ける。シンプルさを優先する
